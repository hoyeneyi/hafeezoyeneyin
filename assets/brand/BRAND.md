# Hafeez Oyeneyin — brand kit

## Logo
The mark is an **HO monogram**: two rounded bars (the H) joined by a ring (the O).
The wordmark is "Hafeez Oyeneyin" set in Geist SemiBold, converted to outlines so it renders the same everywhere without the font installed.

| File | Use |
|---|---|
| `logo-horizontal-on-dark.svg` / `.png` | Mark + name on dark backgrounds (default) |
| `logo-horizontal-on-light.svg` / `.png` | Mark + name on white or light backgrounds |
| `logo-horizontal-white.svg` / `logo-horizontal-black.svg` | One-color versions (embroidery, stamps, overlays on photos) |
| `mark-on-dark.svg`, `mark-on-light.svg`, `mark-white.svg`, `mark-black.svg` | Monogram alone |
| `mark-on-dark-1024.png`, `mark-on-light-1024.png` | Monogram as large PNGs (transparent) |
| `app-icon.svg`, `app-icon-512.png` | Square icon: profile pictures (Facebook, Instagram, LinkedIn, Google Business) |
| `apple-touch-icon.png`, `favicon-32.png` | Website icons (already wired into every page) |
| `og-image.png` | 1200×630 link preview shown when hafeezoyeneyin.com is shared on Facebook, LinkedIn, iMessage, etc. |

Rules: keep clear space around the mark at least the width of one bar. Don't stretch, recolor the bars, or put the pink ring on a busy photo; use the one-color version there.

## Colors
| Name | Hex | Role |
|---|---|---|
| Night | `#07080B` | Background |
| Panel | `#0D0F14` | Raised surfaces |
| Paper | `#F2F3F6` | Primary text, logo bars on dark |
| Signal pink | `#FF5BD6` | The one accent: logo ring, italic highlight word, links |
| Muted | `#7E8594` | Secondary text |

## Type
- **Geist** (600) — headlines, wordmark, UI. Tight tracking (about -0.045em on large headlines).
- **Instrument Serif Italic** — one highlighted word per headline, in Signal pink.
- **Geist Mono** — small labels.
All free on Google Fonts.
